Why it exists

SOPS is great.
The setup isn't.

Stop writing the same scripts for every project to create keys, edit secrets, share access, and run commands. Sudsy puts those bits in one small CLI.

01

Commit encrypted secrets.

The files live versioned with your code. Only the values are encrypted, so diffs still make sense.

02

Give each person their own key.

Grant access to individual environments and remove it when needed. No passing around plaintext files.

03

Run your app normally.

Sudsy decrypts the right environment for a command. You don't need to manually export variables.

How to use it

Four steps. That's it.

01
Initialize.

Create or reuse an age key.

sudsy init
02
Add your secrets.

Edit an encrypted vault for dev.

sudsy edit dev
03
Commit the encrypted files.

Your vault and access rules live in git.

git add .sops.yaml dev.enc.env
git commit -m "Add encrypted secrets"
04
Run your app.

Sudsy gives the command the right environment.

sudsy run dev -- npm start
For your team

Share with your team.

Everyone gets their own key. No shared passwords.

01 / New teammate

Add your public key to the project with sudsy init, then commit and push .sops.yaml.

sudsy init
02 / Someone with access

Pull the change, verify the new key with its owner, and re-encrypt the vaults. Then commit and push the updated files.

git pull && sudsy sync

sudsy sync shows who will gain access and asks for confirmation before re-encrypting.

Worth adding

A little extra protection.

Run sudsy check to catch plaintext .env files, unencrypted vaults, and age private keys. Add it to a pre-commit hook or CI.

sudsy check
Installation

Get Sudsy.

One small CLI, three ways to install it. Sudsy runs on macOS and Linux.

Full installation guide ↗

Latest stable release

curl -fsSL https://sudsy.monotropiclabs.com/install.sh | bash

Install SOPS and age first. The installer verifies the release checksum and puts Sudsy in ~/.local/bin.

Read the installer ↗  ·  Pin a version ↗

Homebrew takes care of the dependencies

brew tap monotropiclabs/sudsy https://github.com/monotropiclabs/sudsy.git
brew install monotropiclabs/sudsy/sudsy

Installs SOPS and age too. Update with brew update and brew upgrade monotropiclabs/sudsy/sudsy.

Install SOPS and age (macOS / Linuxbrew)

brew install sops age

Add Sudsy to your project

npm install --save-dev @monotropiclabs/sudsy

Use npx --no sudsy in your shell, or run Sudsy in an npm script. See the README for other dependency and global installation options.
